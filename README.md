# 🚀 Solana MEV Arbitrage Bot

[![Discord](https://dcbadge.limes.pink/api/server/https://discord.gg/ejEuhN5kcV)](https://discord.gg/ejEuhN5kcV)

A **high-performance Solana on-chain MEV arbitrage bot** that detects and executes profitable opportunities across multiple DEX pools in real time.

The bot computes the **optimal trade size** across routes, accounts for on-chain execution costs, and only execute swap when expected profit is positive.

---

## ✨ Features

- ⚡ **Fully on-chain execution** — minimal off-chain logic for maximum speed
- 📐 **Optimal trade sizing** — computes the most profitable input size per route
- 🔄 **Multi-DEX arbitrage** — routes across a wide range of Solana AMMs
- 🛠 **Production-proven** — actively running on mainnet with real transactions
